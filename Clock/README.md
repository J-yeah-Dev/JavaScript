# Analog Clock

A simple analog clock built with HTML, CSS, and JavaScript using the HTML canvas element. The clock updates every second and shows the current time with hour, minute, and second hands.

## Features

- Real-time analog clock display
- Hour, minute, and second hands
- Clock face with numbered markers from 1 to 12
- Automatic time updates every second
- Minimal single-page design

## How to Use

1. Open `index.html` in a browser.
2. The clock will automatically display the current time.
3. Refresh or keep the page open to view continuous updates.

## Run the App

You can open the file directly in a browser:

```bash
index.html
```

## Project Files

- `index.html` — page structure and canvas element
- `style.css` — page styling and background
- `app.js` — clock drawing logic and time updates

## Notes

This project does not use any external API or dependencies. It is a lightweight front-end clock implementation designed for browser-based use.
