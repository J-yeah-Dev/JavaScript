# Calculator App

A simple browser-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal input support
- Clear button to reset the display
- Backspace button to remove the last character
- Percentage calculation
- Square root calculation
- Result display with error handling for invalid expressions

## How to Use

1. Open `index.html` in your browser.
2. Click the number and operator buttons to enter a calculation.
3. Press `=` to evaluate the expression.
4. Use `C` to clear the display.
5. Use the backspace button to delete the last entry.

## Supported Operations

- `+` for addition
- `-` for subtraction
- `*` for multiplication
- `/` for division
- `%` for percentage conversion
- `√` for square root

## Run the App

Open the project folder and launch `index.html` in a browser.

You can also use a local web server:

```bash
python -m http.server
```

Then open `http://localhost:8000` in your browser.

## Project Files

- `index.html` — calculator structure and button layout
- `style.css` — calculator styling and button design
- `app.js` — calculator logic and calculation functions
